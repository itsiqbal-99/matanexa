# ADR-009 — Evidence-first answers and normalized streaming

- Status: Accepted, 21 Oktober 2026. Disetujui pengguna sebelum Phase 1 dimulai.
- Context: target conversational UX membutuhkan explanation dan real streaming,
  sedangkan integritas teks/referensi hadits adalah prioritas absolut.
- Decision: setiap turn membangun immutable evidence ledger dari retrieval
  yang sudah melewati data policy. Model hanya dapat mengembalikan citation IDs dari
  ledger. Validator fail-closed sebelum final answer. Quote/citation/grade yang tidak
  cocok membuat generated text dibuang dan evidence-only response dikirim.
- Streaming: provider events dinormalisasi menjadi versioned events lalu dikirim
  NestJS melalui SSE. Raw vendor event tidak mencapai frontend. Disconnect/cancel,
  sequence dedup, timeout, partial/final state, dan non-streaming fallback wajib.
- Privacy: jangan simpan chain-of-thought, raw provider payload, prompt, atau full
  conversation logs secara default.
- Consequence: sebagian token delta mungkin perlu dibuffer sampai citation-safe;
  latency sedikit lebih tinggi diterima demi integritas evidence.
- Rejected: streaming raw vendor data, post-hoc citation guessing, model sebagai
  sumber hadith facts, dan simulated typing yang disebut token streaming.
