# ADR-003 — G1: mock search dan chat lokal

- Status: Accepted, 16 Oktober 2026.
- UI menggunakan Next App Router dengan komponen client kecil: sidebar,
  composer, daftar hasil, kartu, detail, modal native, dan hook workspace.
  Next tidak mempunyai endpoint bisnis atau algoritme pencarian.
- Nest `SearchController` → `SearchService` → `MockRepository`; validasi DTO
  melalui Zod pipe, normalisasi NFKC/whitespace/control characters dan batas
  3–300 codepoint. Request strict, page 1–10, limit 1–20, body tak dikenal ditolak.
- Bentuk response ilustratif dalam permintaan G1 disesuaikan ke envelope
  `data/meta` kit agar kontrak v1 konsisten. `data.query`, `data.results`,
  `data.totalCandidates`, serta `meta.modeUsed = mock`. Tidak menduplikasi hasil
  ke envelope lain. OpenAPI mempunyai cabang MockSummary yang eksplisit.
- Enam topik, dua contoh per topik, dua koleksi berlabel simulasi. Matching kata
  utuh dan sinonim statis, ranking deterministik; bukan semantic search. Koleksi
  A/B hanya fixture antarmuka. Field hadithNumber, arabicText, translation, grade,
  sourceUrl dan referenceUrl selalu null; isVerified selalu false. Penanda
  `citation.number = MOCK` adalah ID fixture, bukan nomor hadits. UI tidak
  menampilkan penanda itu sebagai nomor hadits dan tidak membuat tautan sumber.
- Setiap query baru membuat entri riwayat mandiri; filter dan pagination
  memperbarui entri tersebut melalui POST Nest. Tidak ada multi-turn resolution.
- API client memvalidasi shape respons dan menolak payload non-mock/verified;
  timeout 10 detik, AbortController, guard urutan request agar respons lama tidak
  menggantikan query aktif. Pending input dinonaktifkan, tombol batal tersedia.
- React state untuk sesi aktif; localStorage ber-namespace/versi untuk 20 query,
  100 bookmark, tema dan preferensi Arab. Data dibaca setelah hydration,
  divalidasi, dibatasi, dan failure storage tidak memblokir pencarian. Refresh
  mempertahankan daftar riwayat; pilih entri untuk membuka hasil tersimpan.
- Native dialog untuk focus trap/Escape/restore focus; drawer mobile. Font UI
  sistem dan Georgia untuk judul. Lucide konsisten, tanpa download font/gambar.
- Playwright memakai Microsoft Edge headless yang sudah ada, dengan profil
  terisolasi, viewport 1440×960 dan 390×844. Tes positif memakai Nest asli;
  intersepsi hanya untuk fault injection loading/network/invalid/timeout.
- Superdesign dipakai untuk preflight dan konteks desain lokal. Canvas kosong
  dibuat; import HTML ditolak automatic approval review karena ekspor konten
  lokal belum diizinkan. Tidak mengulang upload lewat jalur lain. Implementasi
  dan QA tetap lokal. Tidak ada generasi atau kredit berbayar.
- G2, dataset agama nyata, DB, AI, dan deployment tetap di luar scope.
- QA menemukan watcher API beberapa kali restart ketika output emit hilang dan
  child gagal memuat app.module. Untuk fondasi kecil G1, incremental disk cache
  API dinonaktifkan dan direktori web/artefak dikecualikan dari directory watch.
  Build penuh tetap melalui Nest CLI. Reload dan HTTP diperiksa ulang sesudah
  perubahan; tidak mengandalkan pesan compiler saja untuk klaim server sehat.
