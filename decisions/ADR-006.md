# ADR-006 — Pilot riset lokal dan fallback hybrid

17 Oktober 2026. Instruksi G2.6 terbaru mengizinkan corpus nyata dengan izin
publikasi belum tuntas, khusus penelitian localhost. Ini pengecualian eksplisit
untuk scope development; bukan perubahan aturan publik approved + verified.

`research_only` adalah status sumber tersendiri. Record tetap `draft`, pemeriksaan
identitas pasangan otomatis dicatat terpisah dari tinjauan manusia yang pending.
`local_pilot_hadiths` terpisah dari `published_hadiths`. Tidak ada parameter HTTP
yang dapat memilih scope. `APP_DATA_SCOPE=local_pilot` memerlukan
`NODE_ENV=development`, socket loopback, Host localhost, serta no-store.
Frontend menampilkan label riset, memblokir copy dan tidak menyimpan corpus
pilot dalam localStorage. Dataset dan artefak berteks lengkap diabaikan Git.

Corpus memakai revisi tetap fawazahmed0/hadith-api, edisi Arab/Indonesia Bukhari.
Pasangan harus cocok nomor, koleksi, arabicnumber, reference kitab/hadits dan
metadata section. Kosong/mismatch ditolak. Tidak ada perubahan teks atau grade.
Persetujuan sumber dan verifikasi manusia tidak dapat dilakukan importer.

Lexical tetap di NestJS/PostgreSQL. Indeks turunan mengabaikan awalan sanad
sebelum kutipan pertama, lalu mempertahankan SEMUA sisa dialog, termasuk tanda
kutip bersarang/tidak seimbang. Jika tidak ada kutipan gunakan teks lengkap.
Ini heuristik retrieval, bukan pemisahan matan ilmiah. Normalisasi imbuhan
terbatas, kamus konteks dan intent phrase dapat diaudit; tidak memakai LLM.
Bobot primary/equivalent SQL dibagi `1 + length(document_text)/600` untuk
mengurangi dominasi dokumen panjang. Versi kamus id-lexical-v3.

Provider REST BGE-M3, tabel pgvector(1024), indeks batch berdasarkan hash/model,
cosine scan top100 dan RRF k=60 tersedia. Scope yang sama membatasi semua jalur.
Tidak ada ANN, model lokal atau deployment. Indeks kosong
dideteksi sebelum permintaan embedding. Provider timeout/shape/quota/error
jatuh ke lexical, sedangkan kegagalan database tetap error. Kandidat hybrid
dibatasi gabungan dua daftar top100; total bukan exhaustive corpus recall.

Pada tahap pertama lexical/fallback diprioritaskan. Pengguna kemudian memberi
otorisasi eksplisit untuk indexing dan A/B semantic dengan kredensial lokal.
Batch 4 terjemahan verbatim, throttle 100ms, retry maksimal satu pada timeout/5xx;
auth/quota menghentikan indexing. Upsert batch memeriksa ulang scope/hash sumber
untuk mencegah penyimpanan vector atas record yang berubah saat request berjalan.
Telemetry hanya menghitung request, ukuran input dan usage numerik provider.
Kueri lexical dan embedding berjalan bersamaan setelah index readiness diperiksa.
Saat index kosong, langsung query lexical dengan pagination biasa. Tidak ada
perubahan persetujuan sumber, verifikasi atau batas publikasi. Hasil aktual ada
di G26_HYBRID_REPORT.md; status izin publikasi tetap pending.
