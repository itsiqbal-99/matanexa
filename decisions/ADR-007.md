# ADR-007 — vNext conversational modular monolith

- Status: Accepted, 21 Oktober 2026. Disetujui pengguna sebelum Phase 1 dimulai.
- Context: source saat ini adalah search query-independen sesuai ADR-003. Visi vNext
  meminta multi-turn, grounded generation, streaming, dan provider portability tanpa
  mengganti stack atau mengurangi integritas evidence.
- Decision: pertahankan monorepo dan dua deployable apps. Tambah module
  `conversations` dan `ai` pada NestJS, API v2 berdampingan dengan API v1, serta
  message schema independen provider. Frontend tetap tidak menjalankan business
  retrieval/AI. Server conversation persistence ditunda; localStorage versioned dan
  bounded context dikirim per request pada fase awal.
- Safety: public generation hanya atas approved+verified evidence. Empty/invalid
  citations menghasilkan evidence-only/limitation. Research-only tetap local-only.
- Compatibility: `/api/v1` dan `matanexa.workspace.v1` legacy reader dipertahankan.
- Consequence: bila accepted, bagian ADR-003 tentang query selalu independen dan
  tidak ada LLM akan disupersede hanya untuk API/UI vNext; behavior v1 tetap valid.
- Rejected: microservices, agent framework, server persistence tanpa kebutuhan,
  mengganti PostgreSQL, dan big-bang rewrite.
