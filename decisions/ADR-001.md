# ADR-001 — Next.js + NestJS separate, local first

- **Status:** Accepted for MVP, 2026-10-16.
- **Context:** User requests Next.js front, NestJS if backend needed, no GPU/LLM local/cost, deployment postponed, accurate hadith source.
- **Decision:** NestJS owns all data/AI/retrieval API, Next.js App Router handles UI only; monorepo npm workspaces, ports 3000/4000, Neon remote database, CF AI remote embedding, three dev modes.
- **Trade-offs:** Two dev servers and CORS adds complexity, but clean responsibility and stable future evolution. Remote DB requires Internet in real search mode; cloud quotas constrain volume. Mock works without Internet.
- **Rejected:** all logic in Next.js; paid LLM inference; local GPU/embedding model; heavy Docker Compose; guessing production deployment provider too early.
