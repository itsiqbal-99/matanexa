# ADR-004 — G2 database foundation

Accepted, 16 Oktober 2026, dengan gate runtime/data nyata masih terbuka.

Permintaan G2 terbaru secara eksplisit mencakup lexical dan audit dataset,
meski checklist kit semula memisahkan lexical ke G3. Implementasi minimum ini
tetap G2; tidak mengisi benchmark/corpus G3 atau mengerjakan embedding G4.

Gunakan pg, transaksi, parameter SQL, pool maksimum 3 dan Neon dengan TLS
terverifikasi. Database URL hanya backend. Mock tidak membuat pool. DB error
503 jelas, tanpa mock fallback. Health liveness/configuration bukan readiness.

Migration executable dipisahkan dari SQL desain historis kit: db/migrations/.
Tidak membuat vector/embedding sebagai syarat G2. Skema mempertahankan nama
source_catalog kit, menambah collections/topics/relations/import_runs. Grading
opsional tetap satu set field beratribusi; tidak menambah tabel tanpa data nyata.

View publik memusatkan approved+verified+non-simulation untuk seluruh endpoint.
Approval sumber tidak memverifikasi record. Trigger mengubah konten revisi ke
draft; import tidak dapat memberikan verified, source approval atau grading
tanpa rujukan. Identitas mencakup sumber/koleksi/skema/nomor teks. Impor tetap
menyimpan raw record dan hash, normalisasi hanya field pencarian.

Frontend menggunakan discriminated union mock/verified, guard URL HTTPS dan
payload lengkap, tampilan RTL, atribusi dan grade bersyarat. Tidak redesign UI,
tidak menambahkan database/algoritme pencarian ke Next. Riwayat/simpanan adalah
salinan lokal saat pencarian; status sumber dapat berubah kemudian.

Dataset kandidat pending_review semuanya. Tidak ada import nyata atau klaim
verified tanpa izin dan pemeriksaan manusia. Kredensial Neon belum tersedia
saat audit awal. Tests doubles bukan tes PostgreSQL; suite test:db terpisah dan
skip eksplisit tanpa TEST_DATABASE_URL. Tidak menginstal database lokal.
