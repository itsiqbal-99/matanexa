# Templates

- `.env` templates should be copied to **apps/web/.env.local** and **apps/api/.env**. Never fill example files with secrets.
- `root-package.example.json` is a **reference**, not a tested/generated application manifest. AI agent should install compatible versions and commit lockfile.
- `gitignore.additions` must be merged into repo `.gitignore`.
- OpenAPI response mock uses labelled illustration, not actual religious content.
